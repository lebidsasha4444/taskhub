# Pre-commit hooks

Pre-commit запускає автоматичні перевірки перед кожним `git commit`. Їхня
конфігурація зберігається в корені репозиторію у
`.pre-commit-config.yaml`.

## Встановлення

Встановіть інструмент у своєму віртуальному середовищі та активуйте хук для
цього клонованого репозиторію:

```bash
pip install pre-commit
pre-commit install
```

Команду `pre-commit install` потрібно виконати лише один раз для кожного
локального клону репозиторію.

## Перевірки

Перед комітом виконуються такі перевірки:

- конфлікти злиття та випадково додані великі файли;
- валідність YAML;
- зайві пробіли й відсутній перенос рядка наприкінці файлу;
- linting Python-коду через Ruff;
- форматування Python-коду через Ruff.

Фіксери для пробілів, завершення файлу, Ruff linting і форматування можуть
змінити файли. У такому разі додайте виправлені файли до індексу та повторіть
коміт.

## Ручний запуск

Щоб перевірити весь репозиторій до створення коміту, виконайте:

```bash
pre-commit run --all-files
```

Щоб оновити зафіксовані версії хуків у конфігурації, використовуйте:

```bash
pre-commit autoupdate
```
